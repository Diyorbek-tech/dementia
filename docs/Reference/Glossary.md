# Glossary

Atamalar lug'ati.

- **Assessment (baholash)** — bitta to'ldirilgan so'rovnoma = bitta `Patient` yozuvi. Qarang: [[Data Models]].
- **DiagnosisReport** — baholashga bog'langan AI-simulyatsiyali tashxis (xavf %, status, EEG, tavsiya).
- **Idempotentlik** — operatsiyani N marta bajarish 1 marta bajarish bilan bir xil natija beradi (dublikatsiz). Qarang: [[Diagnosis Service]].
- **Determinizm** — bir xil kirish har doim bir xil chiqish beradi (tasodif yo'q).
- **Atomiklik** — bir nechta DB operatsiyasi "hammasi yoki hech narsa" (`transaction.atomic`).
- **MMSE** — Mini-Mental State Examination (0–30; past = yomonroq).
- **MoCA** — Montreal Cognitive Assessment (0–30; past = yomonroq).
- **AD / MCI / Normal** — Alzheimer's Disease / Mild Cognitive Impairment / Normal — bashorat statuslari.
- **EEG** — elektroensefalografiya; bu yerda to'lqin vizualizatsiyasi uchun namuna ma'lumot.
- **JWT** — JSON Web Token; backend Bearer autentifikatsiyasi. Qarang: [[Auth and Session]].
- **StrictMode** — React'ning dev rejimi; `useEffect`ni ikki marta chaqirib, nojo'ya ta'sirlarni ochib beradi. Qarang: [[Diagnosis Result Page]].
- **IDOR** — Insecure Direct Object Reference; bizda endpointlar user-scoped bo'lib oldini olinadi.
- **MOC** — Map of Content; Obsidian'da yozuvlarni bog'lovchi indeks ([[Home]]).
